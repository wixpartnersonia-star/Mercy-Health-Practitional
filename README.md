# MercyHealthCare

A modern healthcare practitioner website created for **MercyHealthCare**, representing **Mercy Medical Hospital** in Osogbo, Osun State, Nigeria.

> *“Care That Listens. Healthcare That Understands.”*  
> Compassionate healthcare focused on your wellbeing, comfort, and long-term health.

---

## 🌟 Key Features

- **Revolution-Slider-Style Hero**: 
  - Showcases the professional nurse practitioner portrait prominently with layered composition.
  - Staggered typography reveals and smooth animated transitions across 3 slides.
  - Floating real-time medical badges (*7+ Years Experience*, *24/7 Active Care in Osogbo*, *Patient-First Care*).
  - Ambient glowing circles, animated ECG/heartbeat wave line, and top progress timer bar.
  - Touch/swipe support on mobile and 3D mouse parallax tracking.
- **Trust Strip**: Animated counters for years of experience, patient-centered care, and round-the-clock availability.
- **Editorial Introduction**: Split-screen narrative introducing the authentic philosophy of listening first.
- **14 Comprehensive Healthcare Services**:
  - Interactive category filtering tabs (*General Care*, *Preventive Care*, *Family Care*, *Wellness & Counseling*, *Monitoring & Follow-Up*, *Online Telehealth*).
  - Featured deep dive into *Routine Health Screening & Vital Signs Monitoring*.
- **The Care Experience**: 5-step horizontal storytelling pathway (*Listen → Understand → Care → Support → Follow Up*).
- **Global Appointment Booking Modal**:
  - Accessible from every page.
  - Form validation with 1-click WhatsApp transmission button pre-formatting booking details for immediate clinical triage.
- **Dedicated 4-Page Architecture**:
  1. `index.html` - Home Page
  2. `about.html` - About Us (Credentials: B.Sc. Nursing from Osun State University, Philosophy, Timeline, What We Believe)
  3. `services.html` - Our Services (Filterable catalog of 14 clinical services)
  4. `contact.html` - Contact Us (Phones, WhatsApp, Email, Booking form, Osogbo location map & arrival guide)

## 🚀 How to Run Locally

### Option 1: Direct Browser Access
Simply open or double-click `index.html` in any modern web browser (Edge, Chrome, Safari, Firefox). No build step or dependencies required!

### Option 2: Local HTTP Server (Windows PowerShell)
Run the included native server script:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
Then visit: **[http://localhost:5500/](http://localhost:5500/)**
